# Ciudad Verde Calamba HOA Portal

Secure, role-based community portal for the Ciudad Verde Calamba Homeowners
Association. Public informational frontend + restricted, role-authenticated
management dashboard.

**Stack:** Next.js 14 (App Router, TypeScript) · Tailwind CSS · shadcn/ui ·
Supabase (PostgreSQL, Auth, Storage) · Resend · GitHub Actions — 100% free tier.

---

## Quick start

```bash
npm install
cp .env.example .env.local   # fill in your keys (already done locally)
npm run db:migrate           # apply supabase/migrations/*.sql
npm run db:seed-admin        # one-time sys_admin bootstrap
npm run dev                  # http://localhost:3000
```

The seeded System Admin signs in with `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD`
from `.env.local`.

## Roles & authority matrix

| Role | Approve registrations | Assign roles | Activate/Deactivate | Upload docs | Publish docs | See Board Minutes |
|---|---|---|---|---|---|---|
| `sys_admin` | ✅ (incl. President) | ✅ | ✅ anyone | ✅ | ✅ | ✅ |
| `president` | ✅ | ✅ | ✅ (not sys_admin/president) | ✅ | ✅ | ✅ |
| `vice_president` | ✅ | ✅ | ❌ forbidden | ✅ | ✅ | ✅ |
| `doc_controller` | ❌ | ❌ | ❌ | ✅ (staged only) | ❌ | ✅ |
| `board_member` | ❌ | ❌ | ❌ | ❌ | ❌ | ✅ |
| `regular_member` | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ (RLS-enforced) |

These rules are enforced in **three layers**: Next.js middleware (routing),
Server Actions (application), and PostgreSQL RLS + triggers (database).

## Core workflows

1. **Registration** → account created `pending_approval` → Resend email to
   President/VP with a deep link to `/login?redirectTo=/dashboard/admin/approvals`
   → approve (role assigned, activated) or deny (removed). Pending/deactivated
   users are blocked by middleware and their sessions are terminated.
2. **Documents** → Doc Controller/President uploads (PDF/DOCX/PNG/JPG, ≤10MB)
   → staged `pending_review` → President/VP publishes via an atomic,
   row-locked `publish_document()` RPC → if the *"Send email notification"*
   checkbox was set at upload, a batched Resend broadcast goes to all active
   members with clearance, containing deep links
   (`/login?redirectTo=/dashboard/documents/[ID]`).
3. **Tracking numbers** are generated by a `BEFORE INSERT` trigger from
   per-category sequences: `CV-NOTICE-2026-001`, `CV-ANNC-2026-002`,
   `CV-MOM-2026-001`.

## Deployment notes

- **Vercel:** import the repo, set all env vars from `.env.local`
  (change `NEXT_PUBLIC_SITE_URL` to the production URL).
- **GitHub Actions keep-alive:** add `SUPABASE_URL` and `SUPABASE_ANON_KEY`
  repository secrets.
- **Resend free tier:** without a verified domain, Resend only delivers to the
  email address that owns the API key, from `onboarding@resend.dev`. Verify a
  domain in Resend and update `EMAIL_FROM` to enable real member broadcasts
  (free tier: 100 emails/day, 3,000/month).
